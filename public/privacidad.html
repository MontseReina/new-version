Política de privacidad

New Version · última actualización: 22 de octubre de 2026

New Version es una aplicación web de uso personal para registrar hábitos y salud. La usa una sola persona, su titular, y no se ofrece al público. Esta página explica qué datos trata la aplicación, dónde se guardan y con quién se comparten.

Qué datos se guardan

  • Lo que la usuaria registra en la aplicación: ciclo, síntomas, suplementos, alimentación, hidratación, peso, diario y preguntas para sus consultas.
  • Su correo electrónico, para entrar con un enlace sin contraseña.
  • Si conecta Google Calendar u Oura, el permiso de acceso que esos servicios entregan y los datos descritos más abajo.

Dónde se guardan

En una base de datos de Supabase alojada en la Unión Europea (Irlanda). Cada registro está protegido para que solo pueda leerlo la cuenta que lo creó. El código de la aplicación es público, pero no contiene ningún dato personal ni de salud.

Google Calendar

  • La aplicación pide un único permiso: crear y gestionar un calendario propio llamado «New Version». No puede ver ni cambiar ningún otro calendario de la cuenta de Google.
  • A ese calendario solo viajan el título, el día, la hora, el lugar y las notas de las citas que la usuaria crea. Nunca se envían datos de salud.
  • El uso que hace New Version de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Oura

  • Si la usuaria conecta su anillo Oura, la aplicación lee sus datos de sueño, actividad, frecuencia cardíaca, variabilidad, estrés, resiliencia, oxígeno, temperatura y capacidad cardiovascular.
  • Solo lee: no escribe ni cambia nada en la cuenta de Oura. Los datos se guardan en la misma base de datos de la Unión Europea.

Con quién se comparten

Con nadie. Los datos no se venden, no se ceden a terceros, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial. Los únicos servicios que intervienen son los necesarios para que la aplicación funcione: Supabase (base de datos), GitHub Pages (publicación de la web), Google Fonts (tipografías), el servicio de notificaciones del navegador para los avisos al móvil y, si se conectan, Google Calendar y Oura.

Cómo retirar el acceso o borrar los datos

  • Desde la propia aplicación se puede desconectar Google Calendar y Oura en cualquier momento.
  • El acceso de Google también se puede retirar en myaccount.google.com/permissions, y el de Oura desde la cuenta de Oura.
  • Para borrar todos los datos guardados basta con pedirlo en el correo de contacto.
